# Danil — Live Coding Interview Prep

Подготовка к live coding на **React / Node.js / Next.js** (Senior, TypeScript).

Интервью: **среда**. План: **5 дней × 4–5 часов** (пт–вт), в день интервью — только лёгкий разминок (30 мин).

Язык материалов: **задания и код — English**, **объяснения и советы — русский**.

## Как пользоваться

1. Открой [study-plan.md](study-plan.md) и иди по дням.
2. Перед каждой сессией перечитай [interview-strategy.md](interview-strategy.md).
3. Решай задачи из [live-coding-tasks/](live-coding-tasks/README.md) **под таймер**, без AI-автодополнения.
4. Смотри solution только после своей попытки.
5. В день 5 пройди [mock-interviews.md](mock-interviews.md).

## Правила тренировки (важно)

- Таймер на каждую задачу (см. time box в файле).
- Сначала **работающий минимум**, потом edge cases и рефакторинг.
- Проговаривай план вслух (даже если один) — это тренирует коммуникацию.
- После задачи: 5 минут review (что тормозит, какие API забыл).
- Не учи новые темы в день интервью.
